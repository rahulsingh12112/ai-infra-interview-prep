# GPU Infrastructure for AI/ML — Complete Mastery (Zero to Expert)

> **Target:** AI Infrastructure Architect (₹1Cr) | **Style:** Paragraph teaching, zero to enterprise
> **Purpose:** COMPLETE GPU reference. Yeh tera weakest area tha (networking/AWS strong, GPU naya) — ab poora cover.

## Yeh Doc Kyun
AI infrastructure me GPU **central** hai — training aur LLM inference dono GPU pe. Interview me "GPU kaise manage/optimize karoge" zaroor aayega. Tera networking/AWS strong hai par GPU/CUDA naya, isliye yeh doc zero se — hardware samajhna, memory, utilization, cost, multi-GPU, cloud GPU options. Tera infra mindset yahan apply hoga (GPU = expensive resource jise efficiently manage karna).

Jab GPU sawaal aaye: (1) Training ya inference? (2) Model size vs GPU VRAM? (3) Single ya multi-GPU? (4) Utilization kaise max? (5) Cost kaise optimize (spot/sharing/right-size)? Yeh angles se soch.
